# Applied-Energistics-2-AE
Applied Energistics 2 (AE2) — the ultimate digital storage and autocrafting mod for Minecraft. Click the link and the .jar downloads instantly — no pages, no waiting. ME Networks, storage cells, crafting CPUs, molecular assemblers, P2P tunnels, and full mod automation. Works with Forge, NeoForge, and Fabric on 1.18.2–1.21.1.
